# Privacy-Preserving Quality of Experience Research Repository

This repository documents the systematic mapping study focusing on privacy-preserving mechanisms for Quality of Experience (QoE) in network technologies from 2020-2024. The research analyzed relevant studies addressing the intersection of QoE and privacy preservation.

## Repository Purpose

The repository serves to:
1. Document privacy-preserving techniques in QoE measurement and optimization
2. Share methodologies and findings across different application domains
3. Enable transparency and reproducibility in research
4. Support future research in QoE privacy preservation

## Research Overview 

### Application Domains

Main application areas:
- Video Streaming
- Mobile Networks
- Internet of Things
- QoE Forecasting
- Mobile Edge Computing
- Content Caching

Secondary application areas include Virtual Reality, Data Markets, Telemedicine Systems, and others.

### Privacy-Preserving Mechanisms

Primary techniques identified:
1. Federated Learning
2. Encrypted Traffic Analysis
3. Blockchain
4. Differential Privacy
5. Other specialized mechanisms

### Network Context 

Research examines:
- 5G and Beyond 6G Networks
- Different Network Contexts
- WiFi and LTE Networks
- ISP Networks
- Edge Computing Networks
